# Conceito

Uma aldeia global; os tokens são a economia e a aldeia os "digere" sozinha. Ocioso = aldeia dorme, sem perda.

| Evento real | Efeito no jogo |
|---|---|
| Tokens de output | Comida/produção, crescimento da população |
| Input + cache read | Carga de recursos (aldeões levam da mina ao depósito) |
| Thinking tokens | Pesquisa/tecnologias |
| Sessão nova (`session:upsert` com sessionId inédito) | Expedição/novo assentamento, possível avanço de era |
| Subagente | Soldado/explorador |
| Uso de ferramenta (Edit, Bash) | Construção de prédios |
| Fim de sessão | Expedição volta com saque |
| Sessão ativa trabalhando | Aldeões animados |

Eras: Trevas, Feudal, Castelos, Imperial, por marcos de tokens acumulados. Um decisor automático simples escolhe o que construir e treinar. Valores e curvas de balanceamento ainda não definidos.
